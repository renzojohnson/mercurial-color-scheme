# Mercurial Color Scheme

Thank you for installing Mercurial Color Scheme.

## Activation

### Dark (default)

Select `Preferences > Color Scheme > Mercurial` from the main menu.

### Light

Select `Preferences > Color Scheme > Mercurial Light` from the main menu.

### Sublime Text < Build 3149

Select `Preferences > Settings` from the main menu and set:

```json
"color_scheme": "Packages/Mercurial Color Scheme/Mercurial.tmTheme"
```
